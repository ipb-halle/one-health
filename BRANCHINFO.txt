This branch is our development branch for implementing
user registration and login functionality in the One Health project.
Authentication and registration will be implemented using ORCID.
The authentication flow will also include session management,
including cookie- and token-based session handling.

It contains the work on authentication forms, user registration,
login flow, ORCID integration, session management, cookies, tokens,
authentication-related UI, and related backend updates.
